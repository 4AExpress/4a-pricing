# Harness του frontend

```bash
node tests/frontend/run_all.js        # από τη ΡΙΖΑ του repo
node tests/frontend/dashboard.test.js # ένα μόνο
```

Χρειάζεται μόνο Node. Κανένα `npm install`, κανένα δίκτυο, καμία βάση.

## Τι κάνουν

Εξάγουν τις **πραγματικές** συναρτήσεις από τα `frontend/*.html` με ταίριασμα
αγκυλών και τις εκτελούν με ψεύτικο DOM. Δεν αντιγράφουν λογική: αν αλλάξει η
σελίδα, αλλάζει και αυτό που δοκιμάζεται. Ένα harness που ξαναγράφει τη
λογική δοκιμάζει τον εαυτό του.

| harness | τι καλύπτει |
|---|---|
| `clients.test.js` | `fuelState()` / `fuelWarn()` του `pricelist-clients.html`, snapshot προσφοράς |
| `dashboard.test.js` | επιλογή εβδομάδας με ημερομηνία και μεταβολή «επόμενης» στο `fuel-surcharge-dashboard.html` |
| `editor.test.js` | γραμμή επίναυλου και `getFcPct()` του `pricelist-editor.html` |
| `table.test.js` | badge και λωρίδα επίναυλου του `pricelist-table.html` |
| `plline.test.js` | `codForService()` / `plLineHtml()` — γραμμή τιμοκαταλόγου με ⛽ και 💳 |
| `wcag.test.js` | αντίθεση χρωμάτων WCAG AA, διαβάζοντας τα χρώματα **από το αρχείο** |

## Γιατί παγωμένο fixture

`fuel.fixture.099ce2e.json` είναι αντίγραφο του `data/fuel_surcharge_cache.json`
όπως ήταν στο commit `099ce2e` (λήψη 04-10-2026).

Τα harness **δεν διαβάζουν** το ζωντανό cache. Το ζωντανό αλλάζει καθημερινά από
το GitHub Action, άρα μια προσδοκία γραμμένη πάνω σε αυτό θα συμφωνούσε πάντα με
τον εαυτό της — και θα έσπαγε κάθε Δευτέρα χωρίς να έχει αλλάξει κώδικας. Αυτό
συνέβη πραγματικά: 14 έλεγχοι «κόκκινοι» στις 05-10 χωρίς καμία αλλαγή.

Για τον ίδιο λόγο το «σήμερα» είναι **ρητό** σε κάθε περίπτωση. Όπου η
συνάρτηση το παίρνει από `new Date()`, το `Date` σκιάζεται μέσα στο scope του
module (δες `clients.test.js`).

Το fixture είναι αντίγραφο δημόσιου αρχείου του ίδιου repo — δεν εμπίπτει στον
Κανόνα 7. Τα harness δεν περιέχουν απόλυτες διαδρομές, στοιχεία server,
διαπιστευτήρια, ονόματα προσωπικού ή πελατών.

## Προσοχή στις ημερομηνίες των σεναρίων

Το fixture καλύπτει **14-09-2026 έως 18-10-2026**. Ένα σενάριο «παλιά δεδομένα»
πρέπει να χρησιμοποιεί ημερομηνία **εκτός** αυτού του εύρους, αλλιώς δεν είναι
stale. Χρησιμοποιείται το `2026-11-02`.
